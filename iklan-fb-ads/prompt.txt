═══ TUJUAN CAMPAIGN ═══
Primary objective: Lead Generation / Trial Signup
Goal: orang daftar di app.hallowa.id/register dan mulai trial 14 hari.

Decision yang perlu lo bantuin:
1. Conversions vs Leads (instant form) vs Traffic objective?
   - Conversions: kalau pixel + CAPI ready, paling akurat
   - Leads (instant form): bypass landing page, lebih cepat lead
     tapi quality lebih rendah
   - Traffic: cuma kalau pixel belum ready, sebagai temporary
2. Optimization event:
   - "Complete Registration" kalau pixel udah fire event itu
   - "Lead" kalau pakai instant form
   - "Add to Cart" / "InitiateCheckout" sebagai fallback kalau
     volume registration belum cukup
3. Attribution: 7-day click + 1-day view (default) vs 90-day click
   (B2B). Saranin yang pas dengan sales cycle hallowa.

═══ STRATEGI STRUKTUR (HYBRID, BUKAN PURE MANUAL) ═══

Saranin struktur ideal untuk budget Rp100k/hari:

OPSI A — Hybrid Modern (REKOMENDASI):
- 1 Campaign (Sales/Conversions objective)
- 2 Ad Sets:
  * Ad Set 1: Advantage+ Audience (broad, AI-driven targeting)
    Budget: Rp 60k/hari
  * Ad Set 2: Detailed Targeting (cold prospecting yang spesifik)
    Budget: Rp 40k/hari
- 3 Ads per Ad Set (creative testing)
- Total: 6 ad variations untuk learning

OPSI B — Pure Manual (kalau Pixel/CAPI belum mature):
- 1 Campaign
- 3 Ad Sets dengan audience berbeda manual
- 2 Ads per Ad Set
- Total: 6 variations

OPSI C — Funnel-Based (kalau ada existing pixel data):
- Campaign 1 (Cold): Rp 50k/hari, prospecting baru
- Campaign 2 (Warm): Rp 30k/hari, retargeting visitor
- Campaign 3 (Hot): Rp 20k/hari, retargeting trial yang belum upgrade
- Total: 3 campaign, full funnel

Kasih rekomendasi mana yang paling pas berdasarkan status pixel/CAPI
dan data historis hallowa.

═══ CREATIVE STRATEGY (KRITIS — 70% PERFORMANCE) ═══

═══ TECHNICAL SETUP (KRUSIAL — DON'T SKIP) ═══

1. PIXEL CHECK:
   - Cek apakah Meta Pixel udah terpasang di hallowa.id
   - Cek lewat browser Network tab atau Facebook Pixel Helper
   - Atau curl + grep "fbq(" di HTML source
   - Kalau belum: kasih kode pixel + instruksi pasang ke dev

2. CAPI (CONVERSIONS API) — WAJIB 2026:
   - Pixel-only setup di 2026 = miss 50%+ conversion (iOS 14+ killed
     browser tracking quality)
   - Cek apakah CAPI udah terpasang (server-side events)
   - Kalau belum: setup options:
     a. CAPI Gateway (Meta Pixel-as-a-Service, paling gampang)
     b. CAPI integration via partner: Stape, Segment, Wzrd, Northbeam
     c. Custom server-side via Meta Marketing API
   - Setup event deduplication (event_id matching browser + server)
   - Target EMQ (Event Match Quality) score: minimum 6/10, ideal 8+
     - Required: external_id, em (email hashed), ph (phone hashed)
     - Highly recommended: fbc, fbp, client_ip, user_agent
   - Test events di Events Manager → Test Events tab sebelum live

3. EVENT TRACKING:
   Events yang harus tracked di pixel + CAPI:
   - PageView (all pages)
   - ViewContent (pricing page)
   - Lead (form submission, fallback)
   - CompleteRegistration (signup di app.hallowa.id) — PRIMARY EVENT
   - StartTrial (saat user mulai trial 14 hari)
   - Subscribe (saat upgrade ke paid plan) — REVENUE EVENT
   - Custom: TrialActivated (event quality untuk optimization)

4. DOMAIN VERIFICATION:
   - Verify hallowa.id di Business Manager
   - Setup 8 prioritized events di Events Manager (Aggregated Event
     Measurement post-iOS 14)

5. AUDIENCE BUILDING:
   - Custom Audience: Website visitors (30/60/90/180 days)
   - Custom Audience: Pricing page visitors
   - Custom Audience: Trial users (kalau ada email list)
   - Custom Audience: Customer list (paid users)
   - Lookalike: 1% dari paying customers
   - Lookalike: 1% dari trial users

═══ MONITORING & OPTIMIZATION CHECKLIST ═══

Daily (24-48 jam pertama):
- [ ] Spend pace (gak burn budget terlalu cepat?)
- [ ] CTR per ad (target 0.5%+)
- [ ] CPC per ad (target Rp 30k-75k)
- [ ] Pixel + CAPI events firing (cek di Events Manager)
- [ ] EMQ score per event (target 6+)
- [ ] Frequency (jangan over 3 dalam 7 hari di awal)

Weekly:
- [ ] CPL per ad set (track yang under-performing)
- [ ] Creative fatigue (CTR turun >30%? matikan/refresh)
- [ ] Audience overlap (Audiences Insight Tool)
- [ ] Comments & messages (respond dalam <5 menit untuk inquiry serius)
- [ ] Quality ranking, engagement ranking, conversion rate ranking

Bi-weekly:
- [ ] Reallocate budget: matikan ad set CPL >2x average, double
  yang CPL <0.5x average
- [ ] Refresh creative untuk yang fatigue
- [ ] Test new audience based on data

Monthly:
- [ ] Cohort analysis: customer dari FB Ads vs organic, LTV
  comparison
- [ ] Pipeline review: lead → trial → paid funnel di tiap touchpoint
- [ ] ROAS calculation (target 2x dulu, scale ke 4x)

═══ WORKFLOW URUTAN ═══

PHASE 1 — INFRASTRUCTURE (sebelum bikin campaign):
1. Cek Meta Pixel di hallowa.id (browser Network tab + Pixel Helper)
2. Cek CAPI: ada server-side events firing? Cek di Events Manager
3. Verify domain hallowa.id di Business Manager
4. Cek 8 prioritized events di Aggregated Event Measurement
5. Audit existing audiences (Custom + Lookalike)
6. Cek ad account standing (no policy issues)
7. Cek payment method aktif & cukup untuk Rp 3jt + buffer
8. Saranin fix kalau ada issue, BARU lanjut Phase 2

PHASE 2 — CAMPAIGN STRUCTURE:
9. Saranin struktur campaign final (Opsi A/B/C)
10. Tunggu approval gue
11. Buat Campaign di Ads Manager
12. Buat Ad Sets satu per satu (audience, placement, budget,
    schedule, optimization, attribution)
13. Setup creative slots (placeholder dulu sambil siapin asset)

PHASE 3 — CREATIVE PRODUCTION:
14. Generate copy ad (3 variasi minimum) — gue review
15. Spec asset visual yang harus disiapin
16. Gue siapin asset (atau lo bantu generate via skills lain
    kalau ada AI image generation)
17. Upload asset ke Ad creative
18. Preview semua placement (Feed, Stories, Reels, Right column)

PHASE 4 — PRE-LAUNCH REVIEW:
19. Test events di Events Manager (CAPI + Pixel deduplication)
20. Full review semua setting di Campaign Overview
21. Cek estimated daily results — masuk akal gak?
22. Final checklist:
    - [ ] Audience size cukup (gak terlalu sempit, gak terlalu luas)
    - [ ] Budget sesuai
    - [ ] Schedule sesuai
    - [ ] Optimization event yang bener
    - [ ] Attribution window 7-day click + 1-day view (atau 90-day
          untuk B2B, depending recommendation)
    - [ ] Tracking parameters (UTM) di destination URL
    - [ ] Landing page tested (mobile + desktop)
23. GUE yang klik "Publish"

PHASE 5 — POST-LAUNCH (24-48 jam pertama):
24. Monitor delivery (gak underdelivery? gak rejected?)
25. Cek event firing real-time di Events Manager
26. Cek EMQ score per event
27. Identify ad with worst delivery → diagnose
28. Setup automated rules:
    - Pause ad kalau CPL >2x target dalam 3 hari
    - Pause ad kalau frequency >5 dalam 7 hari
    - Notify kalau spend >120% pacing
29. Setup notification: comment baru di ad, ad rejected, budget alert

PHASE 6 — ITERATION (Week 2 onwards):
30. Weekly review: scale yang menang, kill yang kalah
31. Refresh creative tiap 2-3 minggu (B2B fatigue lebih lambat dari B2C)
32. Test new audience hypothesis
33. Monthly: cohort analysis, LTV calculation, ROAS report
