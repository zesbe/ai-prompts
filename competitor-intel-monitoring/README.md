# Competitor Intelligence Monitoring — hallowa.id

Prompt untuk setup CI monitoring system: tau setiap pergerakan kompetitor (Qontak, Qiscus, Wati, dll) dalam <24 jam tanpa effort manual.

## 🎯 Why This Matters

Pasar messaging Indonesia bergerak cepat. Tanpa monitoring, hallowa selalu reaktif. Goal: alert otomatis saat kompetitor launch fitur, ubah pricing, dapat funding, atau muncul di AI search.

## 🛠️ Tools Stack 2026

| Tier | Budget | Tools |
|---|---|---|
| Bootstrap | Rp 0-500k/mo | Google Alerts, Visualping free, manual |
| Lean | Rp 750k-3jt/mo | Visualping paid, PageCrawl, SpyFu, Owler |
| Mid | Rp 4.5-12jt/mo | Semrush, Similarweb, Brand24, full automation |
| Enterprise | Rp 22jt+/mo | Klue, Crayon, full PRM |

## 📡 Monitoring Dimensions

- Website changes (pricing, features, careers)
- Product changes (changelog, docs)
- Marketing & PR (social, ads, events)
- SEO & ranking (keyword, backlink, AI search)
- Business signals (funding, exec hire, M&A)
- Customer voice (G2, Capterra, Reddit)

## 🚀 Cara Pakai

1. Copy [`prompt.txt`](./prompt.txt) → run di sesi baru
2. Setup tools sesuai budget tier
3. Build battlecard untuk top 3 kompetitor
4. Distribute via Slack/Notion ke team
