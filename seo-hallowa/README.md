# SEO + GEO Strategy — hallowa.id

Prompt komprehensif untuk strategi SEO **dan** GEO (Generative Engine Optimization) untuk **hallowa.id** — agar muncul di pencarian Google **dan** AI search engines (ChatGPT, Perplexity, Gemini, Claude, AI Overviews).

## 🎯 Konteks Strategis

hallowa.id adalah B2B SaaS unified messaging platform di pasar Indonesia yang sangat kompetitif. Pemain dominan: **Mekari Qontak, Qiscus, Wati.io, YCloud**. Untuk menang di organic search, butuh strategi yang cover dual discovery (Google + AI) sejak hari pertama.

## 🎯 Target Pages Prioritas (BOFU money pages)

Yang **wajib** ada dan akan paling cepat convert:

```
/vs/qontak          ← "HalloWa vs Mekari Qontak"
/vs/qiscus          ← "HalloWa vs Qiscus"
/vs/wati            ← "HalloWa vs Wati"
/alternatif/qontak  ← "Alternatif Qontak"
/alternatif/qiscus  ← "Alternatif Qiscus"
/alternatif/wati    ← "Alternatif Wati"
```

Comparison/alternative pages = highest conversion intent, low competition relatif (kompetitor jarang bikin comparison ke arah dirinya sendiri).
